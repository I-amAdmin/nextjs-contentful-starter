# סיטונאות מזוז — עמוד בית + בסיס תבנית · הטמעה באלמנטור לפי בלוקים

מבנה ההטמעה: קודם מגדירים את **בסיס התבנית** (צבעים גלובליים, פונטים, הדר ופוטר) פעם אחת — ואז בונים את עמוד הבית **בלוק אחרי בלוק**. כל בלוק הוא Container עצמאי שאפשר לשמור כ־Template ולעשות בו שימוש חוזר בכל האתר.

**דרישות:** תבנית Hello Elementor (או Hello Biz) + אלמנטור. הדר/פוטר בתיאום עם Theme Builder דורשים אלמנטור Pro; בלי Pro אפשר להשתמש בהדר של התבנית.

## שלב ב׳ — עמוד הבית, בלוק אחרי בלוק

צרו עמוד חדש "עמוד הבית" ← Edit with Elementor ← תבנית עמוד: **Elementor Full Width**. כל בלוק להלן = Container אחד. אחרי שבניתם בלוק — קליק ימני ← Save as Template, כדי שישמש אתכם בעמודים נוספים.

### בלוק 1 · HERO
- **Container:** רקע לבן, Padding עליון/תחתון 80px (מובייל 48px), פריסה: 2 עמודות 55%/45% (מובייל: עמודה אחת, תמונה אחרי הטקסט).
- **עמודה ימנית:**
  - וידג'ט Text: תגית `המבצעים מתחדשים כל שבוע` (רקע ורדרד `#FDEBEB`, צבע Accent, פינות 99px, padding ‏6/16)
  - Heading H1: `הסופר של יבנה. מחירים סיטונאיים, שירות של שכונה.` — את "מחירים סיטונאיים" לצבוע ב־Primary
  - Text Editor: `שלושה סניפים ברחבי העיר, מבצעים שמתחלפים מדי שבוע לפי מה שאתם באמת קונים, ושירות אישי שמכיר אתכם בשם. ככה עושים קניות ביבנה.`
  - שני Buttons בשורה: `למבצעי השבוע` (Accent) · `מצאו את הסניף הקרוב` (Outline בצבע Primary)
- **עמודה שמאלית:** Image — צילום אמיתי מהסניף (דוכן ירקות/מעברים). פינות 18px.
- רספונסיביות: במובייל להקטין H1 ל־32px ולמרכז את הכפתורים.

### בלוק 2 · פס אמון
- **Container:** רקע Primary, Padding‏ 20px, 4 עמודות שוות (מובייל: 2×2).
- בכל עמודה וידג'ט Heading קטן (לבן, ממורכז, בלי אייקונים):
  `3 סניפים — בכל רחבי יבנה` · `מבצעים מתחלפים — כל שבוע מחדש` · `כשרות — רבנות מקומית` · `עסק משפחתי — שירות אישי`

### בלוק 3 · מבצעי השבוע
- **Container:** רקע שמנת, Padding‏ 76px.
- שורת כותרת: Heading `שווה להקדים — זה נגמר מהר` + כפתור Outline `לכל המבצעים` בצד שמאל.
- **הדרך המומלצת (מתעדכן לבד):** צרו Custom Post Type בשם "מבצעים" (עם התוסף החינמי CPT UI) ושדות: תמונה, מחיר מבצע, מחיר קודם, תוקף. בעמוד — וידג'ט **Loop Grid** (Pro) עם Loop Item שמעצבים פעם אחת: תמונה מרובעת, באדג' אדום `-30%` בפינה, שם מוצר, מחיר גדול ב־Accent + מחיר קודם מחוק, שורת "בתוקף עד…". עדכון מבצע = הוספת פוסט, בלי לגעת בעיצוב.
- **בלי Pro:** 4 עמודות עם Image + Heading + Text — ולעדכן ידנית כל שבוע.
- רספונסיביות: 4 עמודות ← 2 בטאבלט ← 1 במובייל (או Carousel במובייל).

### בלוק 4 · המחלקות שלנו
- **Container:** רקע לבן, Padding‏ 76px. Heading: `הכל תחת קורת גג אחת`.
- 6 קלפים ברשת 3×2 (טאבלט 2×3, מובייל 1×6): בכל קלף וידג'ט Image עם Overlay גרדיאנט כהה מלמטה + Heading לבן בתחתית:
  `ירקות ופירות טריים` · `מעדנייה ומוצרי חלב` · `קצבייה ועופות` · `מאפים ולחמים` · `בייבי מזוז — לתינוק ולבית` · `חד־פעמי ומוצרי בית`
- Hover: Zoom עדין על התמונה. כל קלף מקושר לעמוד מחלקה.

### בלוק 5 · הסניפים
- **Container:** רקע שמנת. Heading: `תמיד יש מזוז קרוב אליכם`.
- 3 עמודות (מובייל: 1), בכל אחת קלף לבן (גבול קו־הפרדה, פינות 18px, Padding‏ 30px):
  - Heading בצבע Secondary: `מזוז האומן` / `מזוז הדרור` / `בייבי מזוז`
  - כתובת: `האומן 1, יבנה` / `הדרור 25, יבנה` / `שבזי 2, יבנה`
  - טבלת שעות (Text Editor): א׳–ד׳ 06:30–20:00 · ה׳ 06:30–21:00 · ו׳ וערבי חג 06:30–14:00
  - Button מלא רוחב `ניווט בוויז` (Primary) — קישור עומק לוויז לכל סניף.

### בלוק 6 · למה קונים במזוז
- **Container:** רקע Secondary, טקסט לבן. Heading: `סיטונאות במחיר. שכונה בלב.`
- 3 קלפים שקופים-חלקית (רקע לבן 7%, גבול לבן 14%, פינות 18px) עם מספור טיפוגרפי גדול (ללא אייקונים):
  - **01 · מחירים סיטונאיים לכולם** — אנחנו קונים בגדול ואתם משלמים פחות. בלי כרטיס מועדון, בלי אותיות קטנות.
  - **02 · מבצעים לפי מה שאתם צריכים** — המבצעים נבנים כל שבוע לפי הביקוש של הלקוחות, לא לפי מה שנשאר במחסן.
  - **03 · עסק משפחתי מיבנה** — מזוז אליהו ובנו. מכירים את הלקוחות בשם, ותמיד יש מי שיעזור.

### בלוק 7 · עדכוני מבצעים (לידים)
- **Container:** רקע Accent, טקסט לבן, ממורכז, Padding‏ 60px.
- Heading: `המבצעים של שבוע הבא — אצלכם בוואטסאפ`
- Text: `השאירו טלפון וקבלו את עלון המבצעים לפני כולם. בלי ספאם — רק חיסכון.`
- וידג'ט **Form** (Pro) עם שדה טלפון + כפתור `צרפו אותי` (רקע Text כהה) — חיבור לוואטסאפ/מייל/גוגל שיטס דרך Actions After Submit. בלי Pro: כפתור קישור ישיר לקבוצת/צ'אט וואטסאפ.

## שלב ג׳ — רספונסיביות: כללי ברזל לכל הבלוקים
1. עובדים עם **Containers** (Flexbox) — לא Sections ישנים.
2. אחרי כל בלוק: לבדוק בשלושת המצבים (Desktop / Tablet / Mobile) בתצוגה המקדימה של אלמנטור.
3. גדלים גלובליים בלבד; התאמות מובייל דרך הערכים הרספונסיביים של הווידג'ט (אייקון המסך ליד כל שדה), לא עותקים כפולים.
4. תמונות: להעלות ב־WebP, לקבוע Aspect Ratio קבוע (1:1 למוצרים, 16:10 למחלקות) כדי למנוע קפיצות בטעינה.
5. במובייל: Padding אנכי 48px במקום 76px, כפתורים ברוחב מלא בבלוקים 1 ו־5.
